# Step 1: Understand Zero Trust principles

## Overview
Traditional network security models operated on the assumption that anything inside the corporate network could be trusted. This perimeter-based security is no longer effective against modern threats.

## Zero Trust Architecture (ZTA) Principles
Zero Trust operates on the principle of "Never trust, always verify." 

1. **Continuous Verification:** Every access request is fully authenticated, authorized, and encrypted before granting access, regardless of where the request originates.
2. **Least Privilege Access:** Users are given only the minimum level of access required to perform their duties.
3. **Assume Breach:** Security strategies are built assuming that a breach has already happened or is inevitable, emphasizing monitoring and minimizing the attack surface.
