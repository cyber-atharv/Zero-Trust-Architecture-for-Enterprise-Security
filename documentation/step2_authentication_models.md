# Step 2: Define Authentication Models

## Multi-Factor Authentication (MFA)
MFA is an authentication method that requires the user to provide two or more verification factors to gain access to a resource such as an application, online account, or a VPN.
- **Factor 1:** Something you know (Password or PIN)
- **Factor 2:** Something you have (Smartphone authenticator app, Security Token)
- **Factor 3:** Something you are (Biometrics, Fingerprint, Facial Recognition)

## Role-Based Access Control (RBAC)
RBAC restricts network access based on the roles of individual users within an enterprise. 
- Users are assigned roles (e.g., Admin, Employee, Guest).
- Permissions are assigned to roles, not individual users.
- In a Zero Trust environment, RBAC ensures users only have access to resources necessary for their specific job functions (Least Privilege).
